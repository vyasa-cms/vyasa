# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report privately through
[GitHub security advisories](https://github.com/vyasa-cms/vyasa/security/advisories/new),
or email security@vyasa.site.

Include what you found, how to reproduce it, and the version or commit.
We acknowledge reports within 3 working days and aim to ship a fix for
confirmed high-severity issues within 30 days. We credit reporters in the
release notes unless you ask us not to.

## Supported versions

Before 1.0, only the latest release receives security fixes.

## How Vyasa is secured

The security model — authentication, the authorization layer, the plugin
sandbox, rate limits — is described in [docs/SECURITY.md](docs/SECURITY.md).
