description: An AI-native content management system — a fast WordPress alternative written in Rust.
---

Vyasa stores content as structured blocks, keeps themes as data rather than code, and runs plugins in a WebAssembly sandbox with only the capabilities they declare. One server binary and PostgreSQL are all it needs.
