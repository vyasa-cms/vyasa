# Knowledge hub

A centered introduction, prominent search, linked guide cards, and page collections. Article pages include documentation navigation, breadcrumbs and a table of contents.

The theme includes responsive layouts, light and dark color tokens, visible
keyboard focus, and reduced-motion support. Colors, fonts, spacing and radii
come from `tokens.json`; `assets/theme.css` supplies the theme's composition.

Open a draft in AI Studio to edit tokens, section settings, templates and CSS.
Hero alignment and image placement are editable, feature cards accept links,
and section IDs can be used as anchor destinations. Bundled artwork stays with
the theme through preview and publication. AI proposals include CSS changes in
the same revision history as layout changes.

Package and install this directory using the theme packaging workflow in
`docs/THEMES.md`. Existing installed versions are preserved: install the newer
package, preview it, then activate it or publish a Studio draft based on it.
