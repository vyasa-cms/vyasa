# Technology starter

A product landing page with editable execution diagrams, code tabs, feature cards,
and maturity labels. Install from the starter gallery or package this directory
as a `.vytheme`. All text and examples are editable in Studio and page sections.

The sample features and statuses are placeholders, not claims about your product.
Replace them before publishing. Create a `main` menu for navigation.

Code examples remain readable without JavaScript. Enhanced tabs support arrow
keys, Home/End, and copying on secure origins. Entrance motion is optional in
Style scope and respects reduced motion. Layouts stack on phones.

CSS lives in `assets/theme.css`; scripts are supplied by the CMS component runtime.
No external fonts, framework bundles, or remote image requests are required.
